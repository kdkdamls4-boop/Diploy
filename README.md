# 🎮 Diploy Games — Интернет-магазин игр, цифровых ключей и подписок

Учебный проект интернет-магазина видеоигр, лицензий и игровой валюты, разработанный на чистом стеке **HTML5 + CSS3 + Vanilla JavaScript** с сохранением данных в **LocalStorage**.

---

## 🌟 Особенности проекта

1. **Без сторонних фреймворков и сборщиков**:
   - Не требует Node.js, npm, Webpack или Python для работы.
   - Запускается в любом браузере двойным кликом по файлу `index.html`.
   - Весь код структурирован, снабжен подробными русскоязычными комментариями и легко объясняется на защите.

2. **Дизайн в стиле Epic Games Store / Modern Gaming**:
   - Минималистичная темная тема (Dark Mode: оттенки графита `#121212`, `#1c1c1c`).
   - Акцентные цвета: Electric Blue `#0078f2`, Mint Green `#10b981`.
   - Полная адаптивность (ПК, планшеты, смартфоны).

3. **Страницы товара в стиле Steam**:
   - Интерактивная галерея скриншотов с переключением превью по клику.
   - Блоки покупки изданий и наборов (Стандартное, Deluxe Bundle, Franchise Pack) с плашками скидок (`-50%`).
   - Таблица системных требований (Минимальные и Рекомендуемые).

4. **Интерактивная корзина и симуляция оформления заказа**:
   - Изменение количества (+ / -) и удаление позиций.
   - Рабочая система промокодов:
     - `DIPLOY` — скидка **20%**
     - `STUDENT` — скидка **15%**
     - `STEAM` — скидка **10%**
   - Выбор способа оплаты (СБП, Банковская карта, Виртуальный баланс).
   - Моментальная генерация подлинных ключей активации формата `DIP-XXXX-YYYY-ZZZZ` с кнопкой «Скопировать ключ».

5. **Личный кабинет, аккаунты и синхронизация баланса (`profile.html`, `app.js`)**:
   - Полноценная регистрация и авторизация пользователей с сохранением в `localStorage`.
   - Приветственный бонус **+1 000 ₽** на баланс каждому новому зарегистрированному пользователю.
   - Демо-аккаунт: `gamer@diploy.ru` / пароль: `123` (начальный баланс 5 000 ₽).
   - Единая синхронизация баланса: отображение в шапке сайта, в личном кабинете, в способах оплаты корзины и в модальном окне пополнения.
   - Список всех приобретенных ключей с датами покупки, статусом («Готов к активации» / «Активирован») и копированием в буфер обмена.

6. **Панель управления каталогом и Журнал аудита (`admin.html`)**:
   - Защищенный вход только для `peredatprava@gmail.com` с паролем `"1   "` (или `"1"`).
   - Форма добавления нового товара прямо через браузер (название, категория, платформа, цена, скидка, описание).
   - Таблица всех товаров с возможностью удаления и сброса каталога к первоначальному набору.
   - **Журнал системных событий (Audit Logs)**: фиксация регистраций, входов/выходов, покупок, пополнений баланса, действий администратора с фильтрацией по категориям (`AUTH`, `PURCHASE`, `DEPOSIT`, `CATALOG`, `ADMIN`, `SYSTEM`) и кнопкой очистки логов.

## 🚀 Как запустить проект

1. Перейдите в папку проекта `c:\Users\User\Desktop\Projects\Diploy`.
2. Дважды кликните по файлу **`index.html`** (он откроется в вашем браузере: Google Chrome, Яндекс.Браузер, Edge и т.д.).
3. Также можно открыть папку в VS Code и нажать кнопку **Go Live** (расширение Live Server).

## 💡 Шпаргалка для ответа на защите проекта

- **Где хранятся данные?**  
  Данные сохраняются в браузерном хранилище `localStorage` (ключи `diploy_catalog_v2`, `diploy_cart_v1`, `diploy_orders_v1`, `diploy_balance_v1`). Благодаря этому добавленные в корзину товары, созданные заказы, измененный баланс и добавленные через админку товары сохраняются между перезагрузками страницы и закрытиями браузера.

- **Как генерируются лицензионные ключи?**  
  Функция `generateLicenseKey()` в файле `app.js` формирует безопасный псевдослучайный ключ формата `DIP-XXXX-YYYY-ZZZZ` из набора символов `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (исключены похожие символы `0`, `O`, `1`, `I` для удобства ввода).

- **Как работают фильтры и поиск в каталоге?**  
  Функция `filterAndRender()` в `catalog.js` использует методы `Array.prototype.filter()` и `Array.prototype.sort()`:
  - Фильтрует по вхождению подстроки в название/жанр/разработчик (`toLowerCase()`);
  - Фильтрует по радиокнопкам категорий (`games`, `currency`, `subscriptions`);
  - Фильтрует по массиву выбранных платформ (Steam, Epic Games, Xbox, PlayStation, EA);
  - Фильтрует по минимальной и максимальной цене;
  - Фильтрует по флагу «Только со скидкой».
  При изменении любого фильтра список перерисовывается моментально в реальном времени.

- **Как передаются параметры между страницами?**  
  Используется стандартный браузерный API `URLSearchParams(window.location.search)`:
  - `product.html?id=cyberpunk-2077` открывает конкретный товар;
  - `catalog.html?category=games` открывает каталог с предустановленной категорией;
  - `catalog.html?discount=true` открывает каталог со скидками;
  - `catalog.html?search=witcher` ищет товар по поисковому запросу из шапки.

- **Как работает промокод в корзине?**  
  В объекте `PROMO_CODES` (`cart.js`) прописаны коэффициенты скидок: `DIPLOY` (20%), `STUDENT` (15%), `STEAM` (10%). При вводе промокод приводится к верхнему регистру, валидируется, скидка рассчитывается математически (`Math.round(subtotal * percent)`) и динамически вычитается из итоговой стоимости.

- **Как устроена защита админ-панели?**  
  Админ-панель (`admin.html` + `admin.js`) защищена экраном авторизации. Доступ разрешен только главному администратору:
  - **Email администратора:** `peredatprava@gmail.com`
  - **Пароль:** `1   ` (также поддерживается ввод `1`)
  После авторизации открывается форма добавления/удаления товаров и кнопка сброса каталога к эталонным данным. Состояние сессии хранится в `sessionStorage`/`localStorage`, а кнопка «Выйти» блокирует панель обратно.

- **Как устроен виджет быстрого пополнения на главной странице?**  
  Модуль `topup.js` отображает интерактивный блок с 3 вкладками:
  1. **Steam**: пополнение по логину с динамическим расчетом комиссии 4%;
  2. **Roblox**: покупка пакетов Robux (400, 800, 1700, 4500 R$) по никнейму игрока;
  3. **PlayStation**: учет региона (Турция 🇹🇷, США 🇺🇸, Польша 🇵🇱, Великобритания 🇬🇧) и покупка предоплаченных карт PS Store.
  Товар мгновенно передается в корзину с квитанцией транзакции.

- **Как заменены смайлики на SVG-иконки?**  
  В модуле `js/icons.js` создан компактный словарь векторных иконок без внешних шрифтов и библиотек. Функция `getIcon(name)` возвращает оптимизированную SVG-разметку, а `initIcons()` автоматически заменяет атрибуты `data-icon="name"`.

- **Как устроена система аккаунтов и баланса?**  
  Пользователи могут регистрироваться и входить через модальное окно на любой странице. База хранится в `localStorage` под ключом `diploy_users_v1`, а активная сессия — в `diploy_current_user_v1`. При регистрации начисляется приветственный бонус **+1 000 ₽**. Для удобства защиты предзагружен демо-аккаунт `gamer@diploy.ru` (пароль `123`, баланс 5 000 ₽). Баланс пользователя синхронизируется в реальном времени между шапкой, личным кабинетом и корзиной.

- **Как устроен журнал системных событий (Audit Logs) в панели администратора?**  
  Функция `addSystemLog(type, action, details, userEmail)` в `app.js` автоматически протоколирует все критические действия (регистрация/вход `AUTH`, покупка `PURCHASE`, пополнение `DEPOSIT`, операции с каталогом `CATALOG`, действия администратора `ADMIN`). Записи отображаются в `admin.html` с интерактивными фильтрами по категориям и возможностью безопасной очистки.

- **Что будет, если нет интернета при показе проекта?**  
  В файле `app.js` встроен векторный SVG-запасник `FALLBACK_IMAGE_DATA` и обработчик `handleImageError(img)`. Если внешние ссылки на скриншоты не загружаются оффлайн, сайт автоматически подставляет стильную брендовую заглушку `DIPLOY GAMES` без сломанных иконок.

## 🏆 Демонстрационный сценарий для показа преподавателю (1 минута)

1. **Главная (`index.html`)**: показать баннер хита, преимущества магазина, блок горячих скидок и переключатель категорий.
2. **Каталог (`catalog.html`)**: показать живой поиск, фильтрацию по платформам (например, выбрать Steam + скидки) и сортировку по цене.
3. **Страница товара (`product.html`)**: кликнуть на скриншоты в галерее (главная картинка переключается), выбрать издание (например, «Phantom Liberty Bundle» или «Complete Edition»), показать системные требования и нажать «В корзину» или «Купить сейчас».
4. **Корзина (`cart.html`)**: изменить количество позиций кнопками `+`/`−`, ввести промокод `DIPLOY` (скидка 20%), выбрать способ оплаты «Баланс аккаунта» (на счету 5 000 ₽) и нажать «Оплатить и получить ключ».
5. **Модальное окно и профиль (`profile.html`)**: скопировать сгенерированный ключ `DIP-XXXX-YYYY-ZZZZ`, перейти в личный кабинет, переключить статус ключа на «✓ Активирован», затем пополнить баланс через модальное окно на `+1000 ₽`.
6. **Админка (`admin.html`)**: добавить новую игру через форму и увидеть её появление в таблице и каталоге.
